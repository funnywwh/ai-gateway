# v0.4.0（2026-09-13）

新增 stdio MCP 转发模式，让本地 MCP 客户端通过运行中网关使用账户查询和后台管理工具。

```bash
bin/aigw mcp-serve --endpoint https://gateway.example/aigw/mcp --token-env GW_MCP_TOKEN
```

- 从指定环境变量读取 MCP 令牌，权限、吊销、审计、危险操作确认和热更新复用网关 HTTP 服务。
- 现有 `--account` 本地只读模式继续可用；转发模式不读取本地配置或数据库。
- 支持网关路径前缀、逐行 JSON-RPC、即时输出和 SIGINT/SIGTERM 取消。
- 远端使用 HTTPS，HTTP 仅允许 loopback/localhost；禁止重定向与 URL 内嵌凭据、查询参数及片段。
- 输入和响应上限各 10 MiB，每次 HTTP 请求超时 2 分钟；失败非零退出，不自动重试管理操作。

## 验证

`make verify` 与命令包 race 测试通过。真实 HTTP 服务及临时 SQLite 集成覆盖三种令牌权限、
后台写入后读回、令牌吊销和路径前缀；无需付费模型调用。

## 部署与回退

无新增数据库迁移和配置要求。部署仅更新网关二进制，保留原配置、数据库及 Codex 插件。
回退到原网关二进制即可；新转发模式需要本地客户端使用 v0.4.0 二进制，已有 HTTP 服务可继续作为转发目标。
